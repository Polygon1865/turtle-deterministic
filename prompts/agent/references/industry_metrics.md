# 行业关键指标锚点

> 用途：给护城河/周期/政策判断提供数量级参照，**不是结论**。所有引用仍需 URL + 原文引文。

## 使用规则

1. 先判断行业属于哪一类，再引用 2–4 个核心指标；不要一次列 10 个。
2. 与同业对比时用同一口径（合并/母公司、全年/年化、人民币/港币）。
3. 指标异常（如毛利率远高于区间）必须解释：产品结构、会计政策、补贴、一次性收益。
4. 行业数据优先用年报/交易所/统计局/行业协会；网页数据标 `source_type=web`。
5. 没有行业证据时，护城河判断应为 `unknown`，不能仅凭"行业好"给 positive。
