# 护城河与竞争格局（Greenwald 六步）

## 判断对象
公司能否长期维持超额回报：定价权、份额稳定性、进入壁垒。不要把"行业龙头""品牌大"直接等同于护城河。

## 六步分析

1. **行业地图**：先定义竞争战场（细分市场、客户、区域）；列出 5 类进入壁垒（牌照/规模/网络/转换成本/品牌）与 CR4。
2. **量化验证**：5 年 ROE 与门槛对比（8% 合格 / 15% 优秀 / 25% 极强）；份额是否连续 3 年稳定或提升；低谷期利润率是否仍高于同业。
3. **双框架**：
   - 框架 A：非技术壁垒（品牌、渠道、成本、牌照）+ 技术壁垒（专利、工艺、数据）。
   - 框架 B：供给侧优势（资源、成本曲线）、需求侧优势（习惯、转换成本）、规模经济。
4. **虚假优势辨析**：品牌知名度 ≠ 定价权；运营效率 ≠ 结构性壁垒；补贴/渠道压货带来的份额 ≠ 护城河；单年高毛利 ≠ 长期壁垒。
5. **竞对对比**：与 2–3 名主要对手逐项对比（份额、毛利率、ROE、成本、渠道、研发），给出"差距是否可持续"的判断。
6. **可持续性与监控**：给出 3 个监控 KPI（当前值 + 警戒线），例如份额、毛利率、单店/单用户产出。

## 判断标准

- **positive**：份额连续 3 年提升或稳定第一；毛利率/ROE 显著高于同业且非补贴驱动；至少一个壁垒有具体证据（牌照、转换成本、网络效应、成本曲线）。
- **neutral**：份额稳定但未扩大；毛利率与同业接近；壁垒存在但可被资本突破。
- **negative**：份额连续下滑；价格战导致毛利率下行；壁垒被技术/政策/资本削弱。
- **unknown**：没有可引用证据，或证据只来自公司自述。

## 证据要求

- 至少一条量化证据（市占率、毛利率对比、单店/单用户数据、ROE 序列）+ 一条定性证据（研报、年报 MD&A、监管文件、竞对财报）。
- `source_type` 标 `document` / `web`；年报证据填页码或章节。
- 引用原文，不改写；找不到证据就写 `unknown`，不要用"行业普遍认为"代替。

## 常见误判

- 把"行业第一"当成护城河；
- 用单年毛利率判断长期定价权；
- 忽略渠道压货、补贴、会计政策对份额/毛利的影响；
- 把管理层的战略表述当成已实现的壁垒。
