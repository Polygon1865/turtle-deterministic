# 护城河与竞争格局

## 判断对象
公司能否长期维持超额回报：定价权、份额稳定性、进入壁垒。

## 可观察标准
- **positive**：份额连续 3 年提升或稳定第一；毛利率显著高于同业且未靠补贴；客户转换成本/网络效应/牌照等壁垒可被具体证据支撑。
- **neutral**：份额稳定但无扩大；毛利率与同业接近；壁垒存在但可被资本突破。
- **negative**：份额连续下滑；价格战导致毛利率下行；进入壁垒被技术或政策削弱。

## 证据要求
至少一条量化证据（市占率、毛利率对比、单店/单用户数据）+ 一条定性证据（研报、年报 MD&A、监管文件）。`source_type` 标 document/web，年报加页码。

## 常见误判
- 把"行业龙头"直接等同于护城河；
- 用单年毛利率判断长期定价权；
- 忽略渠道/补贴带来的虚假份额。
