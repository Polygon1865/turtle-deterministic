# MD&A 与前瞻信号（D5）

## 目标
从年报"管理层讨论与分析"中提取管理层对未来 1–2 年的判断、风险措辞变化和可验证承诺。

## 可观察项

1. **经营回顾**：收入/利润率变化的原因，是否与财报数字一致；把差异写进 `notes` 或 `discrepancies`。
2. **前瞻指引**：产能、开店、资本开支、分红/回购计划；区分"已承诺"与"愿景"。
3. **风险措辞**：新增风险条目、措辞加重、从"可能"变为"已经"。
4. **承诺兑现**：去年目标 vs 今年实际；未兑现要记录，不要替公司解释。
5. **行业判断**：管理层对竞争格局/需求的判断，与第三方数据是否一致。

## 证据要求

- 引用 MD&A 原文（`source_type=document`，填页码/章节）；
- 至少一条量化信号（收入/毛利/资本开支/分红）和一条措辞信号；
- 只有公司自述、没有交叉验证时，`confidence` 不超过 `medium`；
- 没有可引用原文 → `unknown`。

## 常见误判

- 把"管理层表示有信心"当作证据；
- 把行业展望抄成公司事实；
- 忽略"风险因素"章节的措辞变化；
- 用今年的目标替代去年的承诺兑现检查。
